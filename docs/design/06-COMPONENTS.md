# 06 · Component library

Components are compositions of the five primitives (01) sized by the
proportion ladders. They are layout-agnostic: any product places them; no
component knows where it lives. Instance metrics for the plugin are in 08.

## Arc Control — the instrument's hand

Ghost track (emphasis 16), value arc (accent), value **Point** at the arc
end, **Numeral inside**, Label beneath. 270° sweep; bipolar rises from
top-center. Three tiers from the size ladder — hero, supporting, utility —
adjacent tiers one ladder step (×1.6) apart, with type tier matching
(Display / Value / Body). No body, no pointer, no bezel, nothing behind.

## Marker — a point with an address

The generalization of the plugin's "station": a **Point on a Rule** whose
position *is* information (a chain slot, a channel, a page, a hardware
LED). States per 05; a selected Marker may extend a hairline stem toward
the content it governs. Markers sit on engraved graduations (0.5-strength
ticks) so a rail of Markers reads as a calibrated scale even when empty.

## Switch — a point on a rail

A short Rule with a Point that travels end to end; on = accent at the far
end, off = ink-38 at the near end. Label beside. Replaces every checkbox,
pill and toggle. Motion: `instant`.

## Selector — a word that opens

Body-type value with a Point caret. Open state is an Overlay list; the
current item carries a Point. No box chrome in any state.

## Meter — a rule that moves

Rule (emphasis 16) with accent fill from origin and a Point at the head;
clip turns the Point error for the 1.5 s hold. Identical composition at
any length or orientation.

## Telemetry — numbers as instrument

Numerals set in the type scale with Micro labels beneath, aligned to an
edge, Meters beneath if levels are shown. Never boxed. Value formatting
per 03 — the formatting itself is a signature.

## Field — a calibrated measurement surface

Any live-data surface (spectrum, scope, GR history). Composition:
calibration Rules (emphasis 7) with Micro numerals at one edge, data as
accent per 02 law 3 (≤ 2 layers, emphasis-separated), reference ticks
standing on the Field's datum edge. An empty Field still reads as an
instrument, never as dead space.

## Overlay — a sheet over the face

A night surface bounded by one Rule, sliding over the instrument (04);
beneath it nothing reflows. Search inputs are a bare Rule with a caret.
List rows: Body name, Micro metadata, Point for favorite/selection.

## Wordmark & mark

The star (4-point, drawn from Arc geometry) is the only ornament in the
system. Header controls are words (Body/emphasis 62 · engaged 100), never
icon fonts; an icon may exist only if drawable from the five primitives
and clearer than the word.

## Composition rules

- Every component states its tier (hero / supporting / utility) — tier
  drives size, type and emphasis together; mixed tiers in one element are
  a defect.
- Components never touch; minimum gap 1u, gaps from the cadence scale.
- A new component requires: primitive decomposition, tier behavior,
  states per 05, motion per 04 — reviewed against the recognition test
  before it enters this file.
